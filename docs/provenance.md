# 来源、许可证与维护范围

第一版按维护者本次转换指令，将维护者提供的架构工作资料转成技能。没有从已安装的第三方 review 技能复制内容；它们仅用于识别冲突。源工作台未修改。

三类主要工作资料的摘要与修订标记见 [source-manifest.json](source-manifest.json)。各包也保留自己的 `references/provenance.md`。这些摘要用于记录本次转换输入，不代表存在公开的上游发布地址。

转换包括入口提炼、按阶段/角色/风险拆分、索引与模板抽取、个人机器路径参数化，以及退役与当前 review 协议冲突的旧线程操作。原协议和项目规则 ID 保留。来源文档中的工具、PR 或库引用是方法来源与历史线索，不表示复制了这些产品代码、获得第三方背书或完成当前验证。

仓库沿用原有 Apache-2.0 英文 `LICENSE`，本次核对其归一化换行后的内容与 Apache 官方版本一致，未改写英文条款。中文翻译是本次新增的阅读辅助，不替代英文原文。各技能复制完整英文许可证，并包含来源 `NOTICE`，保证单独分发时保留归属。

本次使用依据是维护者提供材料并明确要求在本 Apache-2.0 仓库实施转换。该事实不构成对其他材料全部内容的许可证判断，也不授权未来任意导入。后续贡献应核实权利、许可证和 NOTICE，不能仅凭可读性就认为可重新许可。

项目名称、owner/repo、Apache 与其他商标仅用于来源和兼容性识别；本仓库不宣称 ASF 项目身份或商标许可。不捏造 ASF 版权归属、发布认证、维护者名单、安全邮箱或已启用的私密报告渠道。

已保留文件级 SHA、历史日期和最小调查证据；未拷贝输入材料中的 API 响应、审计流水、Issue 发布回执或构建产物。导入不刷新历史验证日期，也不声称历史 PR 当前可合并。敏感内容的快速模式检查不能证明资料已完成所有隐私审计。
