# Support

[中文](SUPPORT_CN.md) | English

Use [repository Issues](https://github.com/dubbogo/skills/issues) for usage questions, reproducible defects and workflow proposals. Include the skill, commit, runtime/version, sanitized request, expected versus observed behavior and relevant validation output. Do not include secrets, private code, user data or full transcripts.

Follow [Security](SECURITY.md) for sensitive reports. No paid support, dedicated private mailbox, guaranteed response time or enabled GitHub Discussions feature is assumed. Maintainers may request a smaller offline reproduction.
