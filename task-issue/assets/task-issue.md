## 反馈、纠偏与停止条件
- 验证结果：PASS / FAIL / BLOCKED / NOT_RUN
- 动作：CONTINUE / CORRECT / HOLD
- CONTINUE 条件：当前检查点所有必需项 PASS 或 N/A 且有依据，方向符合 Theme、没有权限越界
- CORRECT 条件：问题在已批准契约范围内，能给出明确的最小纠偏方向
- HOLD 条件：需求/契约歧义、范围或权限变化、关键依赖/环境缺失、当前检查点要求的验证不可用、证据不足或连续两轮纠偏仍失败
- 单一验收项最大连续纠偏次数：2；仍未通过则 HOLD，由人类决定
- HOLD 恢复条件：人类决策 → 分析者更新契约版本 → 受影响项重新验证
- 超过授权范围、外部写操作未授权或需要生产凭据：立即停止相关操作
